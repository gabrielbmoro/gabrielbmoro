# gabrielbmoro — GitHub Profile README

This is a **GitHub Profile repository** (`gabrielbmoro/gabrielbmoro`). Its contents appear on https://github.com/gabrielbmoro.

## What this repo is

- Personal profile page rendered via GitHub Pages (Jekyll, `remote_theme: pages-themes/minimal@v0.2.0`)
- Two READMEs: `README.md` (English) and `README_ptBr.md` (Brazilian Portuguese) — keep both in sync

## No build/test/lint steps

There is no Gradle, npm, CI pipeline, or test runner. The only artifact is the generated GitHub Pages site. Do not attempt to run build, test, or lint commands — none exist.

## Conventions

- The user is referred to as **Moro** or **gabrielbmoro**.
- Changes to `README.md` should be mirrored in `README_ptBr.md` (and vice versa).
- `_config.yml` controls the Jekyll theme — only modify if changing the page layout.
- `assets/img/avatar.png` is the profile avatar.
- `.gitignore` only excludes `.DS_Store`.
